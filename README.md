# EventJoy Hub

Build an app that EpicEventz

Problem statement

Event organizers and attendees traditionally operate using fragmented, disconnected systems. Organizers struggle with administrative overhead, disjointed financial tracking, and a lack of actionable attendee feedback. Simultaneously, attendees face friction when discovering events, securely purchasing tickets, and finding basic support information.

The EpicEventz Objective: To build a unified B2B2C event management platform on Salesforce that bridges the gap between event organizers and attendees. The platform delivers a frictionless ticketing experience while equipping organizers with intelligent, automated management tools.
